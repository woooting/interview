🔍 内存泄露排查实操

每个卡片演示一种泄露场景。先点"制造泄露"再点"清理"，在 DevTools 中观察内存变化。

1. 意外的全局变量

💡 数据挂到了 window 上，GC 无法回收。快照对比看 Array 的 retainers → Window

2. 被遗忘的定时器

💡 定时器回调闭包持有大数组。快照对比看 Array 或 (closure) 的 retainers

3. DOM 引用未释放

💡 变量保存 DOM 引用，DOM 移除后仍存活。快照搜索 Detached HTMLDivElement

4. Map 缓存

💡 Map 的键对象被 GC 后条目仍在。快照对比看 Map 数量增长
